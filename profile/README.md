### Check that a download is genuine

Every direct APK is signed by Teal VPN. Before installing, you can check it:

- **SHA-256 of the file:** listed next to each file on the [releases page](https://github.com/tealvpn/android/releases).
- **Signing certificate (SHA-256):**
  ```
  75:68:15:FB:27:4D:04:A3:8E:E8:C9:BD:CA:A7:1D:0A:AE:65:F3:C6:B1:0D:5F:1C:43:BA:F7:D0:DC:8E:8C:24
  ```
  Check with `apksigner verify --print-certs TealVPN.apk`.

An APK signed with any other key is not ours. Please don't install it.
